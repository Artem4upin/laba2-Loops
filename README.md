# Лабораторная работа: Циклы с пред- и постусловием

## Автор

Чупин Артем (Вариант 6)

## Цель

Освоение базового синтаксиса циклов C++ на примере задачи на нахождение содержания кислорода в стали после раскисления ее кремнием.

## Описание

Программа вычисляет содержание кислорода в стали после раскисления ее кремнием.

## Исходные данные

- Температура: 1873 градуса кельвина
- Первый шаг: 0.025
- Второй шаг: 0.1
- Точка старта: 0.025
- Точка смены шага: 0.1
- Точка конца: 0.7

## Ожидаемые результаты

Программа выводит таблицу значений на участках с разными шагами:

- Si: Концентрация кремния
- O: содержание кислорода в стали после окисления
